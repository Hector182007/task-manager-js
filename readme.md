# 📝 Sistema de Gestión de Tareas

¡Hola! Bienvenido/a a mi proyecto. Este es un administrador de tareas (To-Do List) interactivo que construí desde cero para aplicar y demostrar mis conocimientos en desarrollo web frontend y lógica de programación.

## 🚀 Funcionalidades
* **Agregar tareas:** Interfaz para ingresar nuevos pendientes.
* **Interacción:** Opciones para marcar tareas como "completadas" o eliminarlas de la lista.
* **Memoria persistente:** Uso de `LocalStorage` para que la información no se pierda al recargar o cerrar el navegador.

## 💻 Tecnologías utilizadas
* HTML5 (Maquetación semántica)
* CSS3 (Diseño responsivo)
* JavaScript / Vanilla JS (Manipulación del DOM y lógica algorítmica)
